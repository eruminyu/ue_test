## 문제와 해결 기록

| 시각 | 증상 | 원인 | 해결 |
| --- | --- | --- | --- |
| 1단계 | MaterialInstanceTools list_parameters가 `MI_Manny_01_New ... is not valid MaterialInterface` | 계획서 경로에 하위 폴더 `Manny/`가 빠짐 | find_assets로 실제 경로 `/Game/Characters/Mannequins/Materials/Manny/` 확인 후 사용 |
| 1단계 | 새 GC가 FindCueNotifyAssets/GetCueInfo에 안 나옴 | 에디터 큐 매니저 목록이 새 에셋을 반영하지 않음(추정) | 에셋 레지스트리 태그 GameplayCueName 확인. 8단계 PIE에서 실제 재생 확인 예정 |
| 2단계 | ApplyHit 첫 작성 후 Branch 실행 핀이 끊긴 채 IsValid 매크로 2개가 남음(write_graph_dsl은 성공 반환) | DSL 식 자리의 `Utilities\|IsValid`는 매크로 노드로 만들어지고 exec가 연결되지 않음 | FunctionEntry 외 노드 47개 삭제 후 IsValid 연속 블록 형태로 재작성 |
| 2단계 | InitializeCombat 작성 시 `Unknown exec output "then_2" on Utilities\|FlowControl\|Sequence` | DSL의 Sequence는 then_0, then_1 두 핀만 지원 | Sequence를 then_1 안에 중첩(총 3개). 실패한 호출은 노드를 남기지 않음 |
| 2단계 | GA_SCBase 컴파일 경고 `GetAttackPower was pruned because its Exec pin is not connected` | 다른 객체의 impure 함수를 DSL 식 자리에 인라인으로 써서 exec 미연결 | bind로 먼저 호출 후 return. Result 노드를 지웠더니 출력 파라미터가 사라져 add_function_param으로 다시 추가 |
| 2단계 | GA_ActionBase의 기존 ActivateAbility 이벤트 노드가 사라짐 | `get_node_type_pins "AddEvent\|Ability\|EventActivateAbility"` 조회가 기존 이벤트 노드를 지움 | `add_event K2_ActivateAbility`로 다시 만듦. 이벤트 타입은 핀 조회하지 않음 |
| 2단계 | BP_CombatCharacterBase EventGraph에 연결 없는 OnDied_Event_N/OnRespawned_Event_N이 반복 생성 | Assign 노드의 핀 조회와 DSL 쓰기가 여분 이벤트를 만듦 | 끝에 연결 0인 이벤트를 찾아 delete_node |
| 2단계 수정 | ApplyHit에 출력 추가 후 컴파일 에러 `Could not find a pin for the parameter bGuarded of ApplyHit on  ApplyHit` | 기존 호출 노드(HitTargetsInFront)가 새 출력 핀으로 갱신되지 않음 | `create_node CallFunction\|ApplyHit`로 새 호출 노드를 만들어 재연결, 옛 노드 삭제 |
