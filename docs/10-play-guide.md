# SoulCombat 실행·플레이 안내

이 제작본은 전투 연습 필드와 던전 하나의 싱글 플레이 게임이다. 이번 제작 결과와 실제 통과·미검증 항목은 `09-production-plan.md`와 `checklist.md`에 기록한다.

## 실행

패키지는 저장소의 `SoulCombat/Saved/Packages/Win64Shipping`에 만든다. 이 폴더 **전체**를 유지하고 `SoulCombat.exe`를 실행한다. 실행 파일 하나만 옮기면 콘텐츠를 찾을 수 없다. 처음 실행할 Windows x64 PC에서 런타임 설치가 필요하면 함께 있는 `Engine/Extras/Redist/en-us/vc_redist.x64.exe`를 사용한다. 현재 UE 5.8의 `-prereqs`는 Arm64 장치용 `Engine/Extras/Redist/en-us/vc_redist.arm64.exe`도 함께 포함한다. UE 없는 별도 PC의 실제 설치·실행은 아직 사람 검증 항목이다.

다시 만들 때는 작업 에디터를 저장·종료한 뒤 저장소 루트에서 다음 명령을 실행한다. 스크립트는 다른 에디터를 강제로 종료하지 않는다.

```powershell
powershell -ExecutionPolicy Bypass -File Tools/Package-Game.ps1
```

다른 엔진 설치 경로는 `-EngineDir`, 출력 폴더는 `-ArchiveDir`로 지정한다. `-PlanOnly`는 실행할 경로·인자와 의존 설치 파일의 예상 경로만 보여 준다. 실제 패키징이 끝나면 실행 파일과 두 의존 설치 파일의 존재를 검사한다.

## 조작과 진행

| 입력 | 동작 |
| --- | --- |
| WASD / 마우스 | 이동 / 시점 |
| 좌클릭 | 평타 4타 콤보. 다음 공격 입력을 최대3개 보관 |
| 우클릭 누르기 | 정면 가드. 뒤에서 받는 피해는 가드하지 못함 |
| Shift / Space | 대시 / 점프 |
| Q / E / R | 돌진 베기 / 대지 강타 / 검기 날리기 |
| F | 표시된 게이트 상호작용 |
| Esc | 일시정지 메뉴 |

연습 필드에서 전투와 자원 회복을 확인한 뒤 게이트에 접근해 F로 던전에 입장한다. 일반 전투방은 웨이브의 적을 처치하고, 이벤트방은 제한 시간 안에 봉인석을 파괴한다. 보스방은 바닥 전조와 준비 동작을 보고 가드·대시를 사용한다. 클리어 창에서 필드로 돌아갈 수 있다.

스킬은 SP와 쿨다운을 소비하고, 대시는 스태미나를 소비한다. 스킬은 평타·가드·다른 스킬을 끊고 발동하며, 대시는 피격 경직에서도 탈출할 수 있다. 사망하면3초 뒤 해당 방 체크포인트에서 자원을 회복해 부활하고 **현재 방 진행은 유지**한다.

일시정지 메뉴의 **현재 맵 처음부터 다시**는 플레이어와 방·적을 포함한 월드를 새로 시작한다. **필드로 돌아가기**는 던전을 중단하고 필드 게이트 앞에 복귀한다. **게임 종료**는 실행을 마친다.

## 마지막 사람 검증

자동 PIE 검사는 실제 GA·GE·위젯·맵 이동을 검사하지만 키보드·마우스의 물리 입력과 손맛·화면·청음을 대신하지 않는다. 패키지에서 다음 내용을 확인한다.

- 평타·스킬·대시·가드가 입력과 애니메이션에 맞고, 타격 정지가 불편할 만큼 길지 않은가.
- 피해 숫자·피격 플래시·카메라·명중/가드 소리가 충분히 구분되는가.
- Esc 열기·닫기와 마우스 버튼·키보드 메뉴 이동 후 게임 입력이 정상 복귀하는가.
- 순간이동 없이 던전 전체를 진행하고 사망·재시작·보스·클리어·필드 복귀가 정상인가.

효과음은 `Tools/audio/generate_combat_audio.py`에서 수학적 파형과 고정 난수로 만든다. 외부 음원 샘플을 읽거나 포함하지 않는다. 원본 WAV와 생성 코드를 보관하며 재생 경로 검사와 사람이 듣는 검증을 구분한다.
